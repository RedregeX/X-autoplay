X TikTok Autoplay v2

INSTALL
1. Unzip this archive.
2. Open chrome://extensions
3. Turn Developer mode on.
4. REMOVE or disable the old version first.
5. Click Load unpacked.
6. Choose the x-tiktok-autoplay-v2 folder.
7. Refresh any already-open X tabs.

HOW IT WORKS
- The most visible video automatically plays.
- Other videos are paused.
- When you scroll, playback switches to the next visible video.
- Before Chrome allows autoplay sound, the video is allowed to play muted so it still loads.
- Your first click anywhere on X unlocks sound for the page.
- If necessary, a small "Enable autoplay sound" button appears at the bottom-right.

Chrome itself can block unmuted autoplay before a user interaction. An extension content script cannot fully bypass that browser-level policy.
